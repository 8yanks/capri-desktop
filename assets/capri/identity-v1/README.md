# Identity reference for generated poses

`first-approved-illustrations.png` preserves the initial approved Capri illustration sheet; `default-master.png` is the corrected working full-body model.

Use the upstream `../capri-full.png` for slender anatomy and angular construction. Use the early sheet for the rectangular acid-green mask, concentric cyan optic, angular wink and thin zigzag mouth. Keep hair outside the eyes and mouth. Costumes change clothing, not the character's anatomy or face.

Generated replacements: `../poses-v3`, `../actions-v2`, `../wardrobe-v2`. They were regenerated against these references rather than the rejected oversized-hair costume sheets. Upright width/height is approximately 0.48; gesture/lying poses naturally occupy a wider silhouette.

They are new interpretations, not a pixel-exact trace. Alpha bounds and detected mask landmarks support extraction and QA; visual face review remains necessary. No new runtime image model or dependency is required.
